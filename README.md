Приложение «Карта воспоминаний» помогает путешественникам сохранять и структурировать свои поездки в удобном цифровом формате.
Вы можете создавать поездки, указывая страну, город, даты и личное описание, а затем добавлять к ним воспоминания о конкретных местах — с автоматическим определением координат через геокодирование, проставлением оценок от 1 до 5 и записью личных заметок.
Каждое место можно пометить тегами («архитектура», «музей», «пляж» и др.), а затем легко находить нужные воспоминания внутри поездки по комбинации тегов — например, все музеи или все места, связанные с кухней.
Всё это отображается на интерактивной карте, превращая разрозненные впечатления в целостную историю путешествия.
Безопасность и приватность лежат в основе приложения: каждый пользователь видит только свои поездки, доступ к данным защищён с помощью JWT-аутентификации со сроком действия 2 часа,
а проверка прав происходит на каждом этапе запроса.
Реализована ролевая модель — обычные пользователи управляют своими воспоминаниями, а администраторы контролируют каталог тегов.
Интеграция с бесплатным сервисом геокодирования OpenStreetMap Nominatim позволяет автоматически определять координаты и адреса по названию места,
а поддержка интерактивных карт делает навигацию по воспоминаниям интуитивно понятной.
 

Реализовано: 
- Разработка backend-части на Java (Spring Boot): база данных, ORM-модели, 
репозитории, сервисы, REST-контроллеры
- Реализация CRUD-функционала
- Реализация регистрации и авторизации: JWT-токены, разграничение доступа, 
роли USER/ADMIN
- Интеграция с внешними API: геокодинг адресов (координаты для маркеров, 
поиск места по названию, автозаполнение адреса)
